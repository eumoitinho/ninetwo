# ninetwo-sdk

A lightweight TypeScript SDK for Twenty CRM.

## Installation

```bash
npm install ninetwo-sdk
# or
yarn add ninetwo-sdk
```

## Usage

```typescript
import {} from /* your exports */ 'ninetwo-sdk';
```

## Development

```bash
# Build
npx nx build ninetwo-sdk

# Lint
npx nx lint ninetwo-sdk
```
